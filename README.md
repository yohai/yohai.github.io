# yohai.github.io

Website of Yohai Bar-Sinai's research group: https://yohai.github.io

Jekyll site adapted from the [al-folio](https://github.com/alshedivat/al-folio) theme (MIT, see `LICENSE`).
Pushing to `master` builds and deploys to the `gh-pages` branch via `.github/workflows/deploy.yml`.

- Team: `_data/team_members.yml` (photos in `assets/img/`)
- Publications: `_bibliography/papers.bib` (previews in `assets/img/publication_preview/`, PDFs in `assets/pdf/`)
- Running locally and upstream policy: `how_to_run_and_sync.md`
